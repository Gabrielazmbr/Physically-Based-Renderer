# Chapter 6 controlled Blender scenes

Save the Blender file created by
`tests/evaluation/blender_comparison/setup_controlled_scenes.py` here as
`controlled_comparisons.blend`. The setup script is the reproducible source;
the `.blend` stores the inspected Cycles reconstruction used for final renders.

The Country Kitchen remains separate under
`assets/production_scenes/kitchen_scene/blender/` because it is a production
asset rather than a synthetic controlled test.

Generated EXR renders do not belong in this asset folder. They are stored in
the corresponding `outputs/evaluation/6_blender_comparison/` render folders.
